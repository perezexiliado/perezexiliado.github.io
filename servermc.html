CÓMO ENTRAR

Da igual si jugás desde PC, consola o celu: hay lugar para todos.

Java Edition

  1. Abrí el launcher oficial de Minecraft (versión 1.21.6 en adelante).
  2. Andá a Multijugador → Agregar servidor.
  3. Pegá la IP exiliados.minehost.pro y conectate.

Bedrock (celu, consola, Windows 10/11)

  1. Andá a Jugar → Servidores → Agregar servidor.
  2. Pegá la IP ultra4.minehost.pro y el puerto 25418.
  3. Guardá y conectate — se juega perfecto contra jugadores de Java.
